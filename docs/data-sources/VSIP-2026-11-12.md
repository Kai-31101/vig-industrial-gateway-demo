# VSIP public project catalogue — 12 November 2026

Source index: https://www.vsip.com.vn/en/projects/

Scope: 22 industrial park projects and 15 positive published land inventories. The three Sun Casa residential projects were discovered but excluded from the industrial property catalogue. Expo analytics, demo accounts and request fixtures are outside this replacement.

## Evidence and normalization

- `vsip-public-facts-2026-11-12.json` captures source URLs, retrieval date, source field strings and official image URLs. `src/vsipProjects.json` is the curated application input.
- Project detail pages take precedence over directory summaries. VSIP II Binh Duong's `2.045 ha` headline is normalized to 2,045 ha using its explicit `2,045 ha` overview table.
- Decimal commas are normalized. Ambiguous multi-phase industrial areas remain unknown rather than flattening multiple values into one number.
- Location names follow the source, including legacy province names; the UI explicitly says this. They are not presented as verified current postal addresses.
- Published inventory has no effective date. Retrieval date is not represented as an inventory effective date. Zero is retained only when explicitly published; missing values remain null.
- Land inventories are project aggregates, not individual plots. They do not prefill requested plot size or prove a size match. No invented factory units, prices, handover dates, occupancy derivations, coordinates, salary figures, tax terms or payment schedules remain in the park/property dataset.
- Operational status remains unconfirmed unless separately evidenced; tenant counts and establishment years do not prove current operational status.
- Public source pages are marked reviewed, not legally verified. They are source references, not establishment decisions or business registration certificates. No blanket verified-profile badge is assigned.
- Images are remote images published by VSIP, potentially including renderings. Source placeholders and the duplicated Hai Duong image on Hai Phong pages are omitted. Missing images use the existing neutral empty state.
- Communications Department is the published group contact, explicitly distinguished from a project leasing desk.
- Thai Binh utility capacities and Nghe An I / Binh Duong III industry categories are taken from their respective project pages.

## Refresh

Run `python scripts/capture-vsip.py` (Python + BeautifulSoup). This updates evidence only. Review source changes before updating the curated application data; the capture script never publishes changes automatically.

## Validation

`npm run build` checks TypeScript and production bundling. `npx vitest run src` runs application tests. The repository-wide `npm test` also discovers separate platform-builder Node test files unsupported by Vitest; use the scoped application command for this change.

This developer source identifies the joint venture and a phase under development. It says lots are available but gives no remaining area, so no inventory quantity is invented.
- QTIP industrial land is 349.45 ha overall, distinct from 65.38 ha for phase 1, per the VSIP project overview. Vietnamese name corrected to Khu công nghiệp Quốc tế Quảng Trị (QTIP).
- Four projects without reliable project imagery use the existing local conceptual industrial-park image: Hai Phong I, Hai Phong II, Nghe An IV and Quang Ninh. All display an explicit illustration label, including on detail pages. A failed external image also falls back to this labeled illustration; if the illustration fails, a neutral empty state terminates retries.
- Unknown available area is displayed as Contact for availability on cards. Explicit zero quantities remain zero.
- VSIP's QTIP page reuses the same image URLs as Thai Binh; the independent developer image is preferred. Capture normalizes whitespace in alt labels so non-breaking spaces do not hide images during later research.
